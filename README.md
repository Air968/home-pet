## 线上部署

- **访问地址**：`http://8.137.14.195`（阿里云 ECS · Ubuntu 24.04 · Nginx + Python 后端）
- **架构**：Nginx 托管 `index.html` 静态页 + `/api/` 反代后端（127.0.0.1:9001）+ `/uploads/` 图片静态托管（30 天缓存）
- **管理员账号**：`admin`（初始密码 `admin`，家长端 → 账号管理中修改）；全局素材（形象替换/物种/品种）仅管理员可改
- **数据存储**：账号数据 `/var/www/petapp/data/<sha256(用户名)>.json`；全局素材 `global.json`；图片 `/var/www/petapp/uploads/`（自动压缩为 WebP）

## 核心功能（V19 生产版）

- **云端账号体系**：注册 / 登录 / 跨设备数据同步 / 断网离线兜底 / 老账号本地数据自动迁移上云
- **学习任务**：英语听写（12 套词库，幼儿园~六年级×上下册，参考人教 PEP）、语文阅读（28 篇课文按日轮换 + Chrome 实时语音转文字 + AI 出题评分）、数学口算（3 题，断点续做，按正确率奖励）、应用题（50 题库按日轮换，AI 批改）、科学问答、体育打卡（家长确认）
- **宠物系统**：24 只宠物（普通 6 + 稀有 5 + 珍贵 5 + 神兽 8），蛋等级孵化制（Lv.5 破壳），进化链（品质限制阶段数），品质边框（白/蓝/紫/金），饱食心情进度条，摸摸头每日限一次
- **家长后台**：档案管理（多孩子数据隔离）、学情总览、任务配置、AI 判定引擎（DeepSeek/OpenAI/自定义，无 Key 自动降级程序判定）、奖励经济（**现实奖励自助上架/改价/下架**）、宠物规则、形象替换（管理员权限）、防沉迷、待确认验收、账号管理（角色/改密/云端状态）
- **商城与仓库**：食物购买（4 品种，库存上限 999）+ 家长自定义现实奖励；错题本查看/移除/清空
- **性能**：上传图片前端自动压缩（等比 720px 内 + WebP，透明保留，GIF 原样）、全图片懒加载
- **防沉迷**：可用时段 + 单次时长强制休息 + 每日娱乐总量（学习任务不受限）

## 界面原型使用说明（V0.7 历史版）

1. 双击 `宠伴学园界面雏形.html` 用浏览器打开（Chrome / Edge / Safari 均可）
2. 打开时会弹出「演示说明」，按顺序体验：英语听写 → 数学口算 → 跳绳提交后到家长端确认 → 领养宠物取名 → 喂蛋孵化 → 宠物详情 → BOSS 战斗 → 商城 → 仓库
3. 顶部可切换孩子端 / 家长端；孩子端顶栏可切换多孩子档案
4. 数据存浏览器 localStorage，右上角「重置演示数据」可随时重来

## 技术约定

- **前端**：纯 HTML + CSS + JavaScript 单文件，零依赖零构建，双击即运行
- **后端**：Python3 纯标准库（`http.server`），无任何第三方依赖，systemd 守护
- **认证**：登录态 token（`secrets.token_hex`）+ 接口级 `X-Upload-Token` + 管理员白名单（服务器端 `global.json.admins`）
- **美术**：程序绘制 SVG 矢量宠物（24 种 × 多进化阶段），家长端「形象替换」可上传自定义图片（自动压缩 WebP）
- **数据安全**：密码 SHA256(salt+pwd) 存储、请求体大小限制、文件名校验防目录穿越
