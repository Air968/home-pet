# 宠伴学园 · 家庭宠物养成学习系统

> 孩子自主完成 AI 安排的学习任务，赚取食物与经验喂养宠物——学习闭环 × 宠物养成 × 防沉迷，专为小学家庭定制。

## 核心设计概要

- **使用者**：孩子（孩子端）+ 家长（管理端），孩子自主操作为主；支持多孩子档案，数据完全隔离
- **学科**：语文 / 数学 / 英语 / 科学 / 体育，按年级（幼儿园~六年级）适配教材难度
- **AI 能力**：DeepSeek API 负责出题、语文朗读评分、应用题批改；口算与单词拼写用程序判定（零成本零延迟），家长后台可逐科切换判定引擎（程序 / AI / 智能混合），无 API Key 自动降级为程序判定
- **部署形态**：阿里云轻量服务器 + Docker，任意浏览器访问；iPad 引导式访问锁定做孩子终端，家长手机可外网远程管理
- **宠物体系**：四档品质（普通/稀有/珍贵/神兽）、14 种内置物种 + 自定义品种、6 阶段进化（蛋→幼年体→成长体→完全体→究极体→超神体），按品质限制最高阶段（普通 4 阶段 / 稀有+珍贵 5 阶段 / 神兽 6 阶段）、六神兽对应六种长期学习成就、领养上限随孩子账号等级扩展
- **仓库系统**：食物分四品种（普通粮/高级粮/节日大餐/稀有食物），BOSS 战掉落稀有食物，库存上限 999
- **战斗系统**：答题回合制 BOSS 战，答对造成伤害，技能攻击双倍伤害/双倍反击，五学科各有 BOSS
- **饱食度**：真实时间流逝（4 点/小时），心情联动衰减，在线/离线均按真实时间计算
- **防沉迷**：三层防线——可用时段 + 单次时长强制休息 + 每日娱乐总量（战斗与商城随时可玩，学习任务不受限）

## 界面原型使用说明（V0.7）

1. 双击 `宠伴学园界面雏形.html` 用浏览器打开（Chrome / Edge / Safari 均可）
2. 打开时会弹出「演示说明」，按顺序体验：英语听写 → 数学口算 → 跳绳提交后到家长端确认 → 领养宠物取名 → 喂蛋孵化 → 宠物详情（6 阶段进化链/装扮/玩耍/放生）→ BOSS 战斗 → 商城买装扮穿戴 → 仓库查看食物
3. 顶部可切换孩子端 / 家长端；孩子端顶栏可切换多孩子档案
4. 家长端功能：
   - **档案管理**：创建/编辑/删除孩子档案，选择年级（幼儿园~六年级），年级决定全学科教材难度
   - **任务配置**：逐科开关任务，添加自定义任务（如弹钢琴）
   - **判定引擎**：输入 DeepSeek API Key，切换程序/AI/混合三模式
   - **形象替换**：按物种×进化阶段上传自定义图片（神兽同样支持全部 6 阶段），物种改名，新增自定义品种（可选品质含神兽）
   - **宠物规则**：调整神兽目标值、饥饿阈值、领养上限规则
   - **防沉迷**：设置可用时段、单次时长、每日娱乐总量
   - **待确认**：验收体育等需家长确认的任务
5. 数据存浏览器 localStorage，右上角「重置演示数据」可随时重来
6. AI 相关环节（出题 / 批改 / 讲解）当前为模拟流程，正式版接入 DeepSeek API

## 开发路线

- **V0.5** 云端基础设施：阿里云服务器 + 域名 HTTPS + Docker 框架 + 双账号体系 + 每日自动备份
- **V1.0** 核心闭环：三学科任务 + DeepSeek 生成批改 + 云语音识别 + 宠物养成（四品质 / 蛋孵化 / 领养上限）+ 家长后台
- **V1.5** 游戏化增强：进化动画 + 六神兽 + 答题回合制战斗 + 学科周 BOSS + 商城
- **V2.0** 内容与洞察：科学题库 + 短文库扩充 + 学情周报可视化
- **V3.0** 扩展：多孩档案 / 安卓平板适配 / 寒暑假模式 / 服务器迁移工具

## 技术约定

- 原型阶段：纯 HTML + CSS + JavaScript 单文件，零依赖，localStorage 持久化
- 正式版：Web 应用（前端 + Node/Python 后端 + SQLite/PostgreSQL），Docker 容器化部署
- 美术方向：程序绘制 SVG 矢量宠物（版权干净，14 种 × 6 进化阶段 = 84 个形态完全重画）；家长端「形象替换」面板可按阶段上传自定义图片（蛋图片按物种独立）；装扮系统（6 件装扮，购买后在宠物详情穿戴）
